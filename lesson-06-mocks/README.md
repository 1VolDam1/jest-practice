# Лекция 6. Моки и паттерн AAA

Практика к теме тестовых двойников: `jest.fn()`, проверка вызовов (`toHaveBeenCalled`, `toHaveBeenCalledTimes`, `toHaveBeenCalledWith`), управление ответом зависимости через `mockReturnValue` и структура теста по паттерну **AAA** (Arrange — Act — Assert).

Два задания, для каждого — своя пара «функция + тест» в `src/`:

- `notifyUser.js` / `notifyUser.test.js`
- `getUserName.js` / `getUserName.test.js`

> **Идея лекции.** Реальные функции опираются на «соседей» (почта, база, сервис). Чтобы протестировать функцию, не дёргая настоящую почту или базу, зависимость подменяют управляемым двойником `jest.fn()` — и проверяют не только что функция вернула, но и **как** она вызвала соседа.

---

## Задание 1. `notifyUser` — проверяем, КАК вызвали зависимость

`notifyUser(mailer, user, text)` отправляет пользователю уведомление через переданный почтовый клиент `mailer`.

**Спецификация.**

- если у `user` нет `email` — бросить ошибку `"У пользователя нет email"` и ничего не отправлять;
- иначе — вызвать `mailer.send(user.email, text)`;
- вернуть `true`.

> `mailer` передаётся аргументом специально — чтобы в тесте подставить мок вместо настоящей отправки письма.

**Тесты.** Стройте по паттерну **AAA** (подготовка → действие → проверка):

- [ ] `mailer.send` вызван **ровно один раз** (`toHaveBeenCalledTimes`) и **с правильными аргументами** (`toHaveBeenCalledWith(email, text)`).
- [ ] У пользователя без `email` функция бросает ошибку, а `mailer.send` **не вызывается** (`not.toHaveBeenCalled`).

## Задание 2. `getUserName` — управляем ответом зависимости

`getUserName(repo, id)` возвращает имя пользователя, беря его из репозитория `repo`.

**Спецификация.**

- вызвать `repo.findById(id)`;
- если пользователь найден — вернуть его `name`;
- если `repo.findById` вернул `undefined` (не найден) — вернуть строку `"Аноним"`.

**Тесты.** Здесь зависимость не просто вызывается, а **возвращает** значение, которым пользуется функция. Задайте ответ через `mockReturnValue`:

- [ ] Найденный пользователь: `repo.findById` возвращает `{ id: 1, name: "Аня" }` → функция вернула `"Аня"`; проверьте, что `findById` вызван с `id` (`toHaveBeenCalledWith`).
- [ ] Не найден: `repo.findById` возвращает `undefined` → функция вернула `"Аноним"`.
