# 🧪 Практика по курсу «Основы автоматизированного тестирования на Jest»

Репозиторий с практическими заданиями к курсу. Вы **форкаете** его себе, по ходу лекций выполняете задания в своих файлах и **пушите** решения в свой форк.

Каждая лекция — отдельная папка. Внутри: `README.md` с заданием, а также заготовки функций и тестов в `src/`. Ваша работа — реализовать функции по спецификации и покрыть их тестами так, чтобы `npm test` был зелёным.

> Курс построен на **Jest 30** и современном синтаксисе ES-модулей (`import` / `export`).

---

## Что нужно установить

- **Node.js 18 или новее** (проверьте: `node --version`).
- **npm** (ставится вместе с Node).
- Редактор кода (например, VS Code).

---

## Как начать (пошагово)

### 1. Форкните репозиторий

Нажмите **Fork** вверху страницы репозитория — у вас появится своя копия.

### 2. Склонируйте свой форк

```bash
git clone https://github.com/ВАШ_ЛОГИН/jest-practice.git
cd jest-practice
```

### 3. Установите зависимости

```bash
npm install
```

Одна команда ставит всё необходимое (Jest, Babel) — список зависимостей уже прописан в `package.json`.

### 4. Проверьте, что всё работает

```bash
npm test
```

На свежем форке тесты **зелёные**, но помечены как `todo` — это список задач, которые вам предстоит выполнить. Так и должно быть.

---

## Как выполнять задания

1. Откройте папку нужной лекции и прочитайте её `README.md`.
2. Реализуйте функцию в файле-заготовке `src/<имя>.js` (уберите строку с `throw`).
3. Напишите тесты в `src/<имя>.test.js` — замените `test.todo(...)` на настоящие тесты.
4. Запустите проверку и добейтесь зелёного:

```bash
npm test                 # все тесты
npx jest lesson-05       # только одну лекцию
npm run test:watch       # авто-перезапуск при изменениях
```

5. Зафиксируйте и отправьте решение в свой форк:

```bash
git add .
git commit -m "Лекция 5: параметризованные тесты"
git push
```

Если в вашем форке включены **GitHub Actions**, при каждом пуше тесты автоматически прогонятся на сервере — во вкладке **Actions** будет видно ✅ или ❌.

## Полезные команды

| Команда | Что делает |
| --- | --- |
| `npm test` | Прогнать все тесты |
| `npm run test:watch` | Перезапускать тесты при изменении файлов |
| `npm run test:coverage` | Показать отчёт о покрытии |
| `npx jest lesson-04` | Запустить тесты только одной лекции |

---

## Частые вопросы

**`npm test` пишет «no tests found».** Убедитесь, что файл теста называется `имя.test.js` — по этому шаблону Jest его находит.

**Тест зелёный, хотя функция не готова.** Возможно, остался `test.todo(...)` — он не выполняет проверок. Замените его на настоящий тест.

**`SyntaxError: Cannot use import statement…`** Зависимости не установлены или установлены не полностью — выполните `npm install` в корне репозитория.
